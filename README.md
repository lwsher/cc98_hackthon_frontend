# CC98 AI+

> 面向浙江大学 CC98 论坛的 AI 搜索与新帖订阅工具
> 当前状态：Internal Beta

CC98 每天都在产生新的讨论，也沉淀了大量值得重新发现的内容。

CC98 AI+ 沿着这条信息流向两个方向工作：

* **AI 搜索向后看**：从已有讨论中寻找、阅读和整理信息。
* **订阅提醒向前看**：持续关注新的讨论，在感兴趣的内容出现时及时提醒。

我们希望让 CC98 上真正有价值的信息，在需要的时候更容易抵达你。

![CC98 AI+ 在 CC98 页面中的搜索界面](docs/images/cc98-ai-search-overview.png)


## AI 搜索

你可以用一句自然语言描述自己想了解的问题，插件会理解问题，自动尝试多个搜索方向，在 CC98 中寻找相关主题，并阅读帖子和回复。最后，它会把分散在不同讨论中的经验、共识和分歧整理成一份回答，同时保留原帖链接，方便你核对来源或继续阅读。

它希望减少两类重复劳动：一是反复猜测和组合关键词，二是在大量帖子与楼层之间手工筛选、归纳信息。无论是了解课程与考试、升学就业、校园生活，还是快速回顾一个长期受到关注的话题，都可以先得到一份有出处的讨论概览，再决定要深入阅读哪些原帖。

CC98 AI+ 不会建立论坛的独立全文索引或向量数据库，搜索仍然依赖 CC98 原有的搜索能力。AI 的作用是理解你的问题、寻找合适的搜索方向，并阅读和整理实际找到的讨论，而不是脱离论坛内容凭空生成答案。因此，搜索效果也会受到相关帖子能否被 CC98 搜到的影响。

AI 搜索支持：

* 实时展示搜索、筛选、阅读和总结进度；
* 根据实际找到的 CC98 内容生成回答；
* 保留来源帖子，方便回到原始讨论；
* 使用用户自己的 CC98 登录状态和 LLM API Key；
* 支持直连、RVPN / ZJU-Connect 和 WebVPN。

完整搜索流程运行在浏览器扩展中，不依赖 CC98 AI+ 后端。


## 订阅提醒

对于还没有出现、但你不想错过的信息，可以提前创建订阅。我们的后端服务器会代替你“水 98”，在你关注的新帖出现时，通过**邮箱**或**钉钉**提醒你。你也可以在插件的通知列表查看历史通知。

订阅表达式支持简单组合：

| 符号  | 含义     |
| --- | ------ |
| 空格  | `AND`   |
| `/` | `OR` |

其中 `OR` 的优先级高于 `AND`。同一个事物可能有多种表述，比如 “微积分 / vjf”，使用 `/` 可以让搜索结果更完整。

你可以随时创建、暂停、恢复或删除订阅。扫描由后端持续完成，因此关闭浏览器不会影响已经创建的订阅。

匹配结果会先进入通知列表，邮箱和钉钉负责额外提醒。即使外部通知发送失败，已经发现的帖子仍会保留。

钉钉提醒需要**用户自行配置钉钉群机器人**。操作说明见[钉钉官方文档](https://open.dingtalk.com/document/dingstart/custom-bot-creation-and-installation)。CC98 AI+ 当前仅支持「加签」安全设置，填写 Webhook 与对应的加签密钥即可。


## 安装

支持 Chrome 以及基于 Chromium 的 Edge 浏览器。

### 从 Release 安装（推荐）

1. 前往本仓库的 [Releases](https://github.com/lwsher/CC98_AI_frontend/releases)；
2. 下载最新版本的扩展压缩包并解压；
3. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`；
4. 开启「开发者模式」；
5. 点击「加载已解压的扩展程序」；
6. 选择解压后的目录；
7. 打开或刷新 CC98。

安装完成后请保留扩展目录。

### 从源码使用

当前版本使用原生 JavaScript 和 Manifest V3，无需额外编译。

```bash
git clone https://github.com/lwsher/CC98_AI_frontend.git
```

随后在浏览器扩展管理页面开启「开发者模式」，选择「加载已解压的扩展程序」，加载仓库根目录即可。


## Security & Privacy

| 数据          | 保存位置        | 使用范围         |
| ----------- | ----------- | ------------ |
| CC98 登录凭证   | 浏览器会话存储     | 仅访问 CC98     |
| LLM API Key | 浏览器本地存储     | 仅调用用户配置的 LLM |
| 订阅内容与通知历史   | CC98 AI+ 后端 | 订阅提醒         |
| 邮箱 / 钉钉配置   | CC98 AI+ 后端 | 外部提醒         |

用户自己的 **CC98 Token 和 LLM API Key 都不会上传到 CC98 AI+ 后端**。


## 对 CC98 服务资源保持克制

AI 搜索会增加自动化 API 请求，因此我们主动限制一次搜索的范围。

搜索请求串行执行并设置请求间隔，对搜索方向、候选主题和阅读内容设置数量限制，重复找到的帖子也会在继续读取前去重。

订阅提醒采用**集中扫描**：后端统一获取全站新帖，再在本地完成不同用户的订阅匹配。因此随着订阅用户增加，对 CC98 新帖接口的轮询数量不会同比增长。

我们希望在改善使用体验的同时，也尽量减少对 CC98 公共服务资源的额外负担。
